# StockPilot

An inventory dashboard with an auditable stock ledger, built for the DevOps capstone.

React → FastAPI → PostgreSQL; Docker, GitHub Actions, Trivy, GHCR, Terraform, Helm, Kubernetes, Prometheus and Grafana.

The original instructor material is preserved under `docs/reference/`. This repository is an independent implementation. Setup and evidence instructions will be added with the working project.
